# CardioRisk AI - Heart Disease Risk Prediction System

An AI-powered web application for cardiovascular risk assessment using machine learning on the UCI Heart Disease dataset.

## Features

- 🤖 **AI-Powered Risk Assessment** - Real-time predictions using multiple ML models
- 📝 **Prediction Explanations** - Understand which factors influenced each prediction
- 💊 **Personalized Recommendations** - Clinical recommendations based on risk level
- 📊 **Clinical Dashboard** - Track patient assessment history
- 🔬 **Model Performance** - Compare models with 5-fold cross-validation

## Models Used

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

## Tech Stack

- **Framework:** Streamlit
- **ML Libraries:** Scikit-learn, NumPy, Pandas
- **Visualization:** Plotly, Matplotlib, Seaborn
- **Data Source:** UCI Machine Learning Repository (Cleveland Heart Disease Dataset)
